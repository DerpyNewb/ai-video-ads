# AI video ads

Eight spec video ads for fictional brands, at 16:9, 9:16 and 1:1, plus five vertical how-to Reels for a fictional wellness page. Google Veo and Gemini Omni generated the clips, Flow Music generated the music, and DaVinci Resolve assembled the edits. Styles include photorealistic product scenes, simulated clay stop-motion, creator-style video, dialogue and a 1990s TV spot. Every clip and still is AI-generated, people included, and so is the music. None of it is client work.

The [showcase](https://derpynewb.github.io/ai-video-ads/) includes production notes and the stills used as video-model references. Automated scans and sampled frame reviews do not certify every frame or the final sound. The soundtracks still need a listening review.

The page is `index.html`. The videos in `media/` are web copies of the delivered files, and `media/stills/` has web copies of the stills each video model was given, with a `-thumb` copy for the page.
