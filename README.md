# AI video ads

Four spec video ads for fictional brands, made with Google Veo 3.1 and Gemini Omni and finished in DaVinci Resolve: a 30-second and a 15-second spot at 16:9, a 9:16 ad for Reels and Stories, and a 1:1 feed post. Every clip is AI-generated; none of this is client work.

The page is `index.html`; the videos in `media/` are web copies of the delivered files.
